Application description

SoundTrack is a music playlist manager. It will help users organise information about songs and place songs into their own playlists.

Registered users will be able to create playlists, change their playlist names and add or remove songs. This will make it easier for them to keep different types of music organised.

Administrators will manage the song catalogue. The application will use HTML pages, a JavaScript web server and an SQLite database. It will not store or play actual audio files.

Possible application names

  • SoundTrack
  • Playlist Manager
  • TrackStack
  • My Music List
  • Song Collection

Types of users

Registered users

Registered users can view songs and create, rename or delete their own playlists. They can also add songs to playlists and remove songs that they no longer want.

Administrators

Administrators can add songs to the catalogue, update song details and remove incorrect song records.

User requirements

  • As a user, I want to create a playlist so that I can organise songs I like.
  • As a user, I want to view my playlists so that I can find my saved songs.
  • As a user, I want to rename a playlist so that its name describes the music inside it.
  • As a user, I want to add and remove songs so that I can keep my playlists updated.
  • As an administrator, I want to add and edit song details so that the catalogue is accurate.
  • As an administrator, I want to remove incorrect songs from the catalogue.

CRUD operations

Create, Read, Update and Delete operations
Operation Example
Create Create a playlist or add a new song.
Read View songs, playlists and playlist details.
Update Rename a playlist or edit song information.
Delete Delete a playlist or remove a song.

Basic database structure

Proposed database tables and fields
Table Purpose Fields
Users Stores user and administrator accounts. id, name, email, role
Songs Stores information about each song. id, title, artist, album, genre
Playlists Stores playlists belonging to users. id, user_id, name, description
Playlist songs Connects songs with playlists. playlist_id, song_id, position

User-interface ideas

  • A homepage explaining what SoundTrack does.
  • A page displaying all available songs.
  • A form for adding or editing a song.
  • A page displaying the current user’s playlists.
  • A page displaying the songs inside one playlist.
  • A form for creating or renaming a playlist.

Biggest challenges

  • Connecting songs and playlists correctly.
  • Checking the information entered into forms.
  • Preventing users from changing another user’s playlists.
  • Creating clear routes between the different pages.
  • Making the application accessible and responsive.

Data requirements

The application will use sample song information for development and testing. Each song will need a title, artist, album and genre. Each playlist will need a name and a connection to the user who created it.

SoundTrack will only manage written information about music. It will not store, upload or stream audio files.
