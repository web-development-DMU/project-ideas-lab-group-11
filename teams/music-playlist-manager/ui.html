User-interface overview

The application will use simple HTML pages and forms. The design will allow users to find songs, create playlists and manage the songs inside their playlists.

The first version will use little or no front-end JavaScript. Most actions will be completed using links, buttons and HTML forms.

Main application pages

  • Homepage: introduces the application and provides links to its main features.
  • Song catalogue: displays all songs and allows users to view song information.
  • My playlists: displays the playlists created by the current user.
  • Playlist details: displays the songs inside one playlist.
  • Song form: allows an administrator to add or edit song information.
  • Playlist form: allows a user to create or rename a playlist.

User interactions

Main user actions and expected results
User action Interface component Result
View all songs Navigation link The song catalogue page opens.
Create a playlist HTML form A new playlist is saved.
Rename a playlist Edit form The playlist name is updated.
Add a song to a playlist Button and form The song appears in the playlist.
Remove a song Remove button The song is removed from the playlist.
Delete a playlist Delete button The selected playlist is deleted.

Accessibility considerations

  • Every form input will have a visible label.
  • Pages will use headings in a logical order.
  • Links and buttons will use clear descriptions.
  • The pages will be usable with a keyboard.
  • Text and background colours will have clear contrast.
  • The layout will adjust for smaller screens.
