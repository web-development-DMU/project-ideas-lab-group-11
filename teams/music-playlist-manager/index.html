About the application

Music Playlist Manager is a web application that will help users organise songs into playlists. Users will be able to create playlists and add or remove songs.

The application will use HTML and CSS for the user interface, a JavaScript web server and an SQLite database. It will store information about songs and playlists, but it will not store or play audio files.

More information is available in the original project proposal .
