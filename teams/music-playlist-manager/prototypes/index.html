Welcome to Music Playlist Manager

This application helps users browse songs and organise them into personal playlists.

Users can create playlists, rename them and add or remove songs. Administrators can manage the song catalogue.

What would you like to do?

  • Browse and search the song catalogue
  • View or create a playlist
  • Manage songs as an administrator

About this prototype

This is an HTML prototype of the page returned by GET /. The links demonstrate how users will move through the application.

The prototype does not connect to the SQLite database yet.
